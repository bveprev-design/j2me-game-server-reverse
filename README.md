# Лордмансер — автономная HTML5-версия

В `web/` находится **самостоятельная браузерная игра по мотивам J2ME-клиента Lordmancer Elite 1.19.0**. Она запускается без J2ME, регистрации, сборки, библиотек и игрового сервера. Для оформления использованы спрайты из `resources/mobak/res/`; код и правила локальной кампании написаны на JavaScript.

## Запуск без сервера

Откройте **`web/index.html`** в современном браузере (в том числе через `file://`). Папка `web/` самодостаточна: чтобы перенести игру, скопируйте её целиком. Интернет во время игры не нужен: все изображения, стили и скрипты находятся рядом с HTML, а запросов к серверу игра не делает.

При желании можно раздавать ту же папку любым статическим хостингом. Для локального предпросмотра по HTTP: `python3 -m http.server 8000 --bind 0.0.0.0 --directory web`, затем `http://localhost:8000/`. **Это необязательно для игры**: никакой игровой сервер или API не используется.

## Как играть

1. Выберите одну из пяти рас и создайте героя. Начните с сундука к востоку от города; в городе можно отдохнуть, нанять войско и купить припасы.
2. Ходите стрелками / `W A S D`, экранным крестом или нажимайте на открытую клетку для прокладки пути. Врата телепортируют между частями земли. `M` — карта, `I` — сумка, `H` — герой, `J` — дневник.
3. В бою выберите союзный отряд, затем доступную клетку для перемещения или врага в радиусе атаки. Можно нажимать на поле мышью/пальцем **или** двигать курсор стрелками / `W A S D` и выбирать клетку пробелом. У каждого отряда один ход в раунде; после перемещения можно атаковать. Молния и лечение расходуют ману, зелье восстанавливает здоровье отряда. «Закончить ход» или `Enter` передаёт ход врагам. `Esc` отменяет выбранное заклинание.
4. Отыщите печати на севере, востоке и юге, победите их стражей и вернитесь в Город Надежды. После победы можно продолжать исследование.

Прогресс автоматически сохраняется в `localStorage`; после перезагрузки страницы нажмите «Продолжить сохранённую игру». Через кнопку ⚙ можно **скачать/загрузить JSON-сохранение** для переноса игры между браузерами и устройствами. Если браузер блокирует `localStorage` для `file://`, партия продолжит работать, и её можно продолжить после возврата в меню *без перезагрузки страницы*; перед закрытием страницы обязательно экспортируйте сохранение вручную. Повреждённые или несовместимые сохранения отклоняются.

## Что отличается от исходного клиента

Репозиторий содержит декомпилированный J2ME-клиент и ресурсы, **но не содержит серверных карт, учётных записей и игровых данных**. Поэтому это не побитный перенос онлайн-мира: вместо сетевых протоколов здесь детерминированная локальная карта 36 × 36, законченная офлайн-кампания, локальная экономика и пошаговые бои 5 × 6. Мультиплеер, чат, SMS, аукцион и синхронизация с оригинальным сервером отсутствуют. Исходные `sources/` и `resources/` не изменены.

## Разработка и тесты

- `web/engine.js` — детерминированные правила (карта, герои, экономика, бои, валидация сохранений).
- `web/game.js` — интерфейс, Canvas-отрисовка, мышь/сенсорное управление, клавиатура и импорт/экспорт.
- `web/styles.css`, `web/index.html`, `web/assets/` — адаптивное оформление и локальные изображения, скопированные из ресурсов клиента.
- `web/tests/engine.test.cjs` — тесты движка на Node.js без внешних зависимостей, в том числе прохождение всей кампании **без выдачи бесплатных ресурсов**.

Запуск обычных тестов: `node --test web/tests/*.test.cjs` (Node.js 20+). Браузерный тест в этой команде пропускается, если нет Playwright. Для дополнительной автоматической проверки открытия `file://`, отсутствия сетевых запросов, боёв, импорта/экспорта и мобильной раскладки установите Playwright и Chromium **только для тестирования** и выполните `RUN_BROWSER_TESTS=1 node --test web/tests/browser.test.cjs` (путь к своему Chromium можно передать через `CHROMIUM_PATH`). Никакие зависимости Node.js не требуются для запуска самой игры.
